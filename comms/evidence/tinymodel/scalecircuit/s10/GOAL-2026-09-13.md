**NO CHEATING** means, concretely, for every run in this window:
1. The 30 eval docs (3-39 minus few-shot) are never trained on, never used to write labels, and
   never used to tune templates, retrieval, prompts or thresholds. All development of templates,
   retrieval and reader prompts happens on a DEV set of train-side docs with gold (docs 40-159 and
   beyond, which also carry the human-style labels); the eval docs are scored once per
   pre-registered change, never iterated on.
2. Gold answers never enter any prompt, retrieval query, or selection rule. The oracle union is a
   diagnostic (D2), never the claimed score. No per-doc wiring choice made after seeing eval F1.
3. The single-pass baseline runs with the same reader, retrieval and paragraph budget as the
   wirings; any retrieval or reader improvement is applied to the baseline too, and the band is
   re-derived from the new baseline. The baseline is never weakened.
4. Training data: synthetic from the generator plus labels I write by hand from the question text
   alone; model outputs never enter training data; eval docs asserted absent before every run.
5. Every change is pre-registered with a banded prediction before its eval number exists, then
   filed on the comms thread with raw evidence. A miss is filed as a miss.
6. Pinned caps stand (3 loop rounds per registered loop; a new loop needs a new pre-registration
   with its own 5-why). "Hard push" means new mechanisms, not moved bands.
